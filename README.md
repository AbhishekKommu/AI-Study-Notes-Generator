# 🤖📚 AI Study Notes Generator

A simple **frontend AI Study Notes Generator** that helps students create short and easy-to-understand study notes from entered topics or text.

## ✨ Features

* 📝 Enter a topic or study text
* 🤖 Generate study notes
* 📚 Create simple summaries
* 🔑 Highlight important points
* 🎯 Easy-to-read notes
* 📱 Responsive design
* 🎨 Clean and simple interface

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure


AI-Study-Notes-Generator/
│
├── index.html
├── style.css
└── script.js


## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter a topic or study text.
5. Click **Generate Notes**.
6. View the generated notes.
